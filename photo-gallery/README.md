# 写真ギャラリーを作る道具

大会の写真フォルダを渡すと、写真一覧ページを作ります。作ったページは、無料の **Cloudflare Pages** で公開できます。
参考にしたのは、全日本ダンススポーツ連盟 西部ブロックの競技写真ページです。

**この道具がすること**
- 大きすぎる写真を、見るのにちょうどよい大きさ（長い辺2400px）に縮める
- 一覧に並べる小さな見本の写真（サムネイル）を作る
- 縦に撮った写真の向きを直す
- 写真に入っている撮影場所（GPS）などの情報を消す。インターネットに出しても安全なようにするためです
- 1ページに120枚ずつ並べた一覧ページ（`index.html`）を作る
- iPhone の写真（HEIC）を JPEG に直す（Mac のみ）
- 大会ごとのページをまとめた「トップページ」を作る

> **用語メモ**
> - **ターミナル**：文字を打ってパソコンに指示を出すアプリです。Mac では「アプリケーション → ユーティリティ → ターミナル」にあります。
> - **Node.js（ノード）**：この道具を動かすためのソフトです。最初に一度だけ入れます。

---

## 最初の1回だけやる準備

1. **Node.js を入れる**
   https://nodejs.org/ja を開き、「LTS」と書かれたボタンからダウンロードして、ふつうのアプリと同じように入れます。
2. **この道具のフォルダに移動する**（ターミナルで）
   ```
   cd ~/claude-home/photo-gallery
   ```
   ※ `~/claude-home` の部分は、このフォルダを置いた場所に合わせて変えてください。
3. **必要な部品を入れる**
   ```
   npm install
   ```
4. **Cloudflare の無料アカウントを作る**
   https://dash.cloudflare.com/sign-up でメールアドレスを登録します。
5. **ターミナルから Cloudflare にログインする**
   ```
   npx wrangler login
   ```
   ブラウザが開くので「Allow（許可）」を押します。

## 大会ごとにやること

### 1. 写真を1つのフォルダにまとめる
例：デスクトップに `2026-10-kyoto` というフォルダを作り、写真を全部入れます。

### 2. ページを作る
```
npm run build -- ~/Desktop/2026-10-kyoto --name 2026-10-kyoto --title "京都大会 競技写真" --date 2026-10-04
```
- `--name`：サイトの名前です。**英小文字・数字・ハイフン（-）だけ**使えます。公開したときの住所にもなります。
- `--title`：ページのいちばん上に出る題名です。トップページにもこの名前で並ぶので、大会名を入れるとわかりやすいです。
- `--date`：大会の日付です。トップページで新しい順に並べるのに使います。省略すると、作業した日になります。

- `--seconds`（なくてもよい）：スライドショーで1枚を見せる秒数です。書かなければ1.5秒です。例：`--seconds 2`
- `--music`（なくてもよい）：スライドショーで流す曲のファイルです（mp3・m4a など）。例：`--music ~/Downloads/song.mp3`
  **市販の曲は著作権の問題になるので使わないでください。** フリー音楽素材など、Webサイトで使ってよいと決められている曲だけにしてください。

写真ページの上には「▶ スライドショーで見る」ボタンが付きます。押すと、写真がゆっくり動きながら1.5秒ごとに自動で切り替わり、曲を入れた場合は音楽も流れます。

iPhone の写真（HEIC 形式）も、そのまま入れて大丈夫です。Mac に最初から入っている変換機能で、自動で JPEG に直します。

2,000枚で数分かかります。終わると `dist/2026-10-kyoto` フォルダができます。
途中で止まっても、もう一度同じ命令を打てば、できているところは飛ばして続きから進めます。

### 3. 公開する
作り終わると、ターミナルに次のような1行が表示されます。それをコピーして貼り付けてください。
```
npx wrangler pages deploy "dist/2026-10-kyoto" --project-name 2026-10-kyoto
```
初めての名前のときは、質問が出ることがあります。そのまま Enter キーを押して大丈夫です。

終わると `https://2026-10-kyoto.pages.dev` のような住所が表示されます。これが公開されたページです。

### 4. トップページを作り直して公開する
トップページは、これまでに作った大会を新しい順に並べたページです。大会を追加するたびに作り直します。
```
npm run top -- --name nori-photos --title "大会写真ギャラリー"
```
最後に出る「公開するには…」の1行を貼り付ければ、`https://nori-photos.pages.dev` に公開されます。

- 大会の一覧は、このフォルダの `events.json` に自動で記録されます。**道具を新しい版に入れ替えるときは、`events.json` と `dist` フォルダを消さずに残してください。**
- 一覧から大会を外すには：`npm run top -- --name nori-photos --remove 2026-10-kyoto`
- 公開した住所が `https://2026-10-kyoto-abc.pages.dev` のように名前と違っていたときは、`events.json` の `"url"` をその住所に直してから作り直してください。

## 気をつけること
- **住所を知っている人は、だれでも見られます。** 検索サイトには出ないように設定していますが、パスワードはかかっていません。
- Cloudflare Pages の無料プランは、1つのサイトに置けるファイルが **2万個まで** です。この道具は1枚の写真から2つのファイルを作るので、**1つのサイトで約9,900枚まで**です。大会ごとに別の名前でサイトを作れば、この上限は気にしなくて大丈夫です。
- 元の写真は変更しません。縮めた写真は `dist` フォルダの中に新しく作ります。

## 開発者向け
- テスト：`npm test`
- 写真の大きさや画質は `build.mjs` の先頭で変えられます。
